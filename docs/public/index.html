AGENT CORE Polaris 智能体核心

持久化任务循环 · 断点续跑 · 审批门禁 · 全程留痕，任务可以跨小时、跨天推进而不丢状态。

01 / ACCESS 平台与接入层 Web · 桌面客户端（macOS / Windows / Linux）· MCP 接入 · 开放接口
02 / RUNTIME 任务运行层 长任务引擎 · 实时进度流 · 预算控制 · 人工审批 · 崩溃恢复
03 / ENGINES 三引擎协同 规划 · 执行 · 校验，一个循环推动整项研究
Navigator · 规划起草并修订步骤清单，计划随证据生长而不是推倒重来核心模块
Helm · 执行一次执行一个动作，异常绝不外抛，失败也变成可推理的观察核心模块
Sextant · 校验逐步核对验收标准，确定性检查先行，模型只在规则无法判定时出场核心模块
04 / FOUNDATION 数据与基础设施 PostgreSQL + pgvector · Redis · Docker Compose · GPU 服务器接入

WHY POLARIS

不只是问答，是会做研究的智能体

可信

每一步产出先过确定性校验，通过才继续；论文数字与引用逐项对账，编造即打回。

可插手

实验跑到拿不准的地方会停下来问你，你回一句，建议被采纳进下一轮继续推进。

可进化

评审标准、辩论人设、代码规范都能做成技能挂到对应环节，还有技能市场共享。

可审计

每个计划、动作、判定与重试全部落库，界面上看得见，事后也回放得了。

为实验室而生

开放生态
