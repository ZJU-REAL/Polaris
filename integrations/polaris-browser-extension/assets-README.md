# Bundled installer asset

The offline extension delivery package places `YFRDownloadBridgeSetup.exe` in this directory. The executable is generated by `tools/yfr-download-bridge/scripts/build-release.ps1` and is intentionally excluded from Git source control.

The slim extension package omits the executable and downloads the same fixed asset name from the latest GitHub Release.

Extension version 0.4.18 captures browser-owned PDF navigation responses, stores verified bytes in extension Cache Storage, and provides a read-only cached-PDF viewer for manual identity review. The bundled bridge is version 0.4.1 and uses exact DOI boundaries before title fallback. Older bridge installations must be replaced by running the bundled setup executable again.
